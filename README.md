# 📊 HR Analytics & Attrition Dashboard

An interactive web application built with **Python** and **Streamlit** to analyze employee data and visualize attrition trends.

## 🛠️ Features
- Interactive plots for monthly income and department analysis.
- Clean and optimized layout with tailored visualization themes.
- Cleaned dataset with automated handling of missing data and outliers.
